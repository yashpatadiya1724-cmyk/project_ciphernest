# Security Policy

## Responsible Vulnerability Disclosure

As a cybersecurity intelligence platform, CipherNest prioritizes security and confidentiality.

If you discover a security vulnerability:
- Please report it directly to: `yashpatadiya1724@gmail.com`
- Include detailed reproduction steps, component details, and impact evaluation.
- All reports receive initial triage and acknowledgment within 48 hours.
- Please do not open public GitHub issues for undisclosed security vulnerabilities.
